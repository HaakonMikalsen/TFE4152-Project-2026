# TFE4152-Project-2026

## Aimspice files
The files are stored in a file structure like this \
aimpiceFiles/subcircuits/gates : contains gate code subcircuits . Names on the form "\[gatename\]Gate" \
aimpiceFiles/subcircuits/components : contains subcircuits built by gates. If needed additonal folders can be made to sort components building up a large component. Names on the form "\[componentName\]" \
aimpiceFiles/transistorModels : contains the modelcard for the spesific technology and the process variation modifier files \
